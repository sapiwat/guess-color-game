# RGB Guessing Game - JavaScript Logic & DOM Exercise

An interactive color-guessing game that challenges players to identify the correct color based on **RGB (Red, Green, Blue)** values. This project was developed as part of an online professional development course on **Udemy**.

## 🚀 Key Learning Outcomes & Skills
Building this game allowed me to master several fundamental web development concepts:
* **RGB Color System:** Deepened my understanding of how digital colors are constructed and represented.
* **Array Manipulation:** Using JavaScript arrays to generate random color sets and selecting a "winning" color from the collection.
* **Conditional Logic:** Implementing game rules to distinguish between "Correct" and "Try Again" states with visual feedback.
* **Refactoring & Clean Code:** Organizing code into reusable functions (e.g., `reset()`, `pickColor()`, `generateRandomColors()`) to follow the DRY (Don't Repeat Yourself) principle.
* **Dynamic Styling:** Manipulating CSS styles in real-time based on game events (e.g., changing the header background to match the correct color).

## 🛠️ Tech Stack
* **HTML5:** Game structure and UI components.
* **CSS3:** Responsive layout and interactive hover effects.
* **Vanilla JavaScript:** Game engine, random color generation, and event handling.

## 📝 Inspiration & Credits
This project was created as part of a Web Development Bootcamp on **Udemy**. 

**Why I chose this project:**
I wanted to bridge the gap between static design and dynamic interactivity. This game required me to think logically about how to handle different "difficulty modes" and manage the state of multiple UI elements simultaneously.
